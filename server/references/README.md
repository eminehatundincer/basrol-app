# Referans görseller

`styles.js` içinde bir tarzın `references` listesinde yazan dosyaları buraya koy
(ör. `anime-1.jpg`, `anime-2.jpg`, `dreamy-1.jpg`).

- Yalnızca `model: "seedance"` olan tarzlarda kullanılır.
- Kullanıcının fotoğrafı her zaman `@Image1`, buradakiler sırasıyla `@Image2`, `@Image3` ... olur.
- Dosya yoksa atlanır; tarz yine çalışır ama referanssız olur.
- Telif hakkı sende olan ya da kullanım izni olan görseller kullan.
