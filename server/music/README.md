# Sahne müzikleri

Video hazır olunca sunucu, sahnenin müziğini yumuşak açılış/kapanışla ekler.
Dosya yoksa video sessiz teslim edilir (hata vermez). Eşleşme: `server/styles.js` → `music`.

| Dosya | Sahneler | Aranan hava |
|---|---|---|
| `osmanli.mp3` | Osmanlı Sarayı | ney, ud, kanun; görkemli saray |
| `gerilim.mp3` | İntikam Dizisi, Mafya Ağırlığı | karanlık gerilim, dizi jeneriği |
| `duygusal.mp3` | Konak Draması, Canlanan Fotoğraf | piyano/yaylılar, duygusal |
| `karadeniz.mp3` | Karadeniz Sevdası | kemençe, tulum |
| `sok.mp3` | Dramatik Zoom | dramatik vuruş, "dun dun dun" |
| `pop.mp3` | Kız Grubu, Klip Çekimi, Dans Akımı | enerjik pop / K-pop |
| `halay.mp3` | Düğün Halayı | davul zurna |
| `epik.mp3` | Sinematik, Aksiyon | epik orkestral fragman |
| `ruya.mp3` | Anime, Rüya | yumuşak ambient, masalsı |
| `nostalji.mp3` | Eski Film | 70'ler, retro, yumuşak |

Kurallar:
- Ticari kullanıma izin veren **telifsiz** parçalar (ör. Pixabay Music lisansı).
- **Content ID'ye kayıtlı olmayan** parçalar seç; yoksa kullanıcıların Instagram/YouTube
  paylaşımlarına telif uyarısı gelebilir.
- Telifli dizi müziklerini (jenerikler, şarkılar) kullanma.
- 20–60 sn yeter; video 8 sn, parça baştan çalar.
